# Taxi Microservices System

Система заказа такси, построенная на микросервисной архитектуре. Проект демонстрирует взаимодействие сервисов через REST и Kafka, использование распределенного кэширования и контейнеризацию.

## 🏗 Архитектура

Проект состоит из следующих компонентов:

* **User Service**: Управление пассажирами и водителями, хранение профилей. Использует PostgreSQL для данных и Redis для кэширования доступных водителей.
* **Trip Service**: Бизнес-логика создания поездок, управление статусами и расчет стоимости.
* **Notification Service**: Асинхронная отправка уведомлений (пассажирам и водителям) через Kafka.
* **Common Library**: Общие DTO, модели безопасности и фильтры, используемые всеми сервисами.

### Технологический стек
* **Java 25** & **Spring Boot 4.0.6**
* **Базы данных**: PostgreSQL, Redis
* **Брокер сообщений**: Apache Kafka (KRaft mode)
* **Документация**: SpringDoc OpenAPI (Swagger)
* **Безопасность** *(WORK IN PROGRESS)*: Spring Security (JWT + Internal API Key)

## 🚀 Инструкции по сборке и запуску

### Предварительные требования
* Docker и Docker Compose

### Запуск
Сборка и запуск всех контейнеров одной командой из корневой директории:
```bash
docker-compose up -d --build
```
После запуска сервисы будут доступны по адресам:
* **User Service**: `http://localhost:8081`
* **Trip Service**: `http://localhost:8082`
* **Notification Service**: `http://localhost:8083`

## 📝 API Документация (Swagger)
Интерактивная документация доступна для каждого сервиса по url `/swagger-ui.html`
