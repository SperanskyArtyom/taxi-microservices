# Taxi Microservices

Проект представляет собой микросервисную систему для сервиса заказа такси. Основная цель — отработка навыков построения масштабируемой архитектуры, работы с фреймворком SpringBoot и контейнеризацией.

## Технологический стек
- **Язык:** Java 25
- **Фреймворк:** Spring Boot 4.0.x
- **Сборка:** Gradle
- **База данных:** PostgreSQL 18.x, Redis
- **Миграции:** Liquibase
- **Инфраструктура:** Docker, Docker Compose
